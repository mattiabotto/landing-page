# landing page
Landing page layout using CSS flexbox layout

## Project description
This project consist in a simple landing page CSS layout, usign a given design. 
The main CSS technique used is flexbox, along with other basics CSS selectors and properties.
The design is not responsive: for now it is working only on desktop, overflowing in smaller mobile viewports.

## Skills and technologies demonstrated
- Simple HTML structure of a landing page
- CSS flexbox model: justify-content and align-items on the two axes, wrap, gap, flex-direction and responsive flex.
- Basic CSS properties and selectors (selector chaining, parent-child selectors, etc...)
- Attention to the detail from a given design (given image with fonts and colors)
